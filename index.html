三维理想磁流体 (3D Ideal MHD) 精确解析平衡方程对照

Counterexamples to Grad's Conjecture — arXiv:2609.26742 & arXiv:2610.07304

1. 理想磁流体静力学平衡与稳态不可压缩 Euler 流的同构性

三维理想磁流体平衡满足 (∇ × B) × B = ∇p 与 ∇ · B = 0。当磁张力可表为标量势梯度 (B · ∇)B = -∇Q 时，平衡方程严格等价于具有 Bernoulli 函数 H = Q + |B|²/2 的三维稳态不可压缩 Euler 流，且压强满足 ∇p = -∇H。这直接推翻了 Harold Grad (1967, 1985) 关于“除对称构型外不存在具有光滑嵌套环面与非常数压强的三维磁流体平衡解族”的著名猜想。

2. 族 I：拉伸非对称 Solov'ev 平衡解 (常旋转变换 ι = 2)

令水平拉长因子 a = √(1+ε), b = √(1-ε)，垂直不对称参数 τ₀ ∈ (-1, 1)，定义 Ω = √(1-τ₀²) 与 s = x²/a² + y²/b²：

F = √[ 1 - (1 - s)² - 4z² - 4τ₀ s z ] > 0
B_x = [(2z + τ₀ s)x - (a/b)F y] / s
B_y = [(2z + τ₀ s)y + (b/a)F x] / s
B_z = 1 - s - 2τ₀ z
ψ = (u + Ω²ε/2)² + v²,   p = p_a - 2ψ/Ω²,   V(δ) = 2π²√(1-ε²)δ / Ω³
β_V = 2(p_b + δ/Ω²) / (1 - Ω²ε²/2 + δ/Ω²),   ∮ dℓ/|B| = 2π/Ω

当 τ₀ = 0 时退化为 Landreman (arXiv:2609.26742 §2) 的仿星器对称解；当 τ₀ ≠ 0 时破缺仿星器对称性 (arXiv:2610.07304 §2)，磁轴在水平投影上由圆变为椭圆并产生相位偏移 γ = arcsin(τ₀)。

3. 族 II：复相位椭圆坐标磁剪切平衡解 (ι'(ψ) ≠ 0)

引入复坐标 ω = x + iy，焦距参数 ε > 0，径向参数 S > 0，垂直尺度 λ > 0 及复相位对称破缺参数 τ₁ ∈ ℝ：

K = ω̄ √(1 + ε/ω̄²),   Ξ = ωK + π/2 - S + iτ₁,   ν̃(ζ) = (ε/2)sin(2ζ) + τ₁
B_x + iB_y = i e^(-iλz) sin(Ξ) / (2K),   B_z = Re[e^(-iλz) cos(Ξ)] / λ
ψ = [sin²(λz) + λ² B_z²] / 2,   p = p_a - ψ/λ²
dχ/dζ = [√(4σ² + ε²) + ε cos(2ζ)] √[(1 - 2ψ sin²χ) / (cosh²ν̃ - 2ψ)]

当 τ₁ = 0 时退化为 Landreman (arXiv:2609.26742 §3)；增大 |τ₁| 不仅破缺仿星器对称性，还会使磁剪切 ι'(ψ) 由正转负，同时压缩磁面体积并降低 β_V。
